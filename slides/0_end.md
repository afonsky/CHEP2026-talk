# Results

* We present `robust_select` - an algorithm for identifying robust machine learning models.
    * Framework-agnostic, works with any supervised-learning ML / DL model;
    * Allows models to be identified up to 80% faster than an exhaustive search;
    * Systematic uncertainties are provided for the chosen models;
        * Applying it to a single model makes it possible to determine its systematic uncertainties.

* The use of adaptive statistical criteria will enable even more effective selection.

* The method is available as standalone Python library: <img src="/gitlab-logo-500-rgb.png" style="display:inline;height:2.8em;vertical-align:center;margin-right:0.em" /><a href="https://gitlab.com/AndrewShevelev/robust_select">robust_select</a>
    * Provided with implementation examples in PyTorch and TensorFlow.
